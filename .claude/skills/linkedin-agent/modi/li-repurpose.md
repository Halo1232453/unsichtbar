# /li-repurpose · Ein langer Inhalt wird eine Woche Beiträge

Ein guter langer Inhalt (Blogartikel auf der Website, Video, Newsletter,
Podcast, Transkript, Notizen aus einem Kundengespräch) steckt voller Beiträge.
Die meisten holen einen raus und werfen den Rest weg.

## Eingabe

Ein Transkript, ein Artikel, ein Newsletter, ein Skript, eine
Gesprächszusammenfassung. Bei einer URL: Seite lesen, wenn ein Werkzeug dafür da
ist, sonst um den Text bitten. Alles lesen, bevor etwas herausgezogen wird.

Bei Kundengesprächen: Kundennamen und vertrauliche Zahlen bleiben draussen,
ausser voice.md gibt sie frei.

## Herausziehen, nicht zusammenfassen

Eine Zusammenfassung eines Videos ist kein Beitrag. Niemand will die
Zusammenfassung. Den Inhalt durchgehen und herausziehen, was allein steht:

| ziehen | was |
| --- | --- |
| **Behauptungen** | jeder Satz, der eine Diskussion auslösen würde |
| **Zahlen** | jede Zahl, jeder Betrag, jede Dauer, jeder Prozentwert |
| **Geschichten** | jeder Moment mit einer Person, einer Szene und einem Preis |
| **Mechanismen** | jede Erklärung «so funktioniert das» |
| **Fehler** | jedes Eingeständnis, dass etwas schiefging |
| **Sätze** | jeder Satz, der schon so zitierbar ist |

Erst auflisten, was gefunden wurde, mit Anzahl, dann schreiben. Ergibt der
Inhalt weniger als vier Elemente, ist er dünn, und vier Beiträge daraus wären es
auch. Das sagen.

## Dann die Woche bauen

Jedes Element wird ein Beitrag, und jeder Beitrag steht komplett für sich: Die
Leserin hat das Original nicht gesehen und wird es nie sehen. Nie «wie in
unserem letzten Blogartikel erwähnt». Der Beitrag ist die Sache.

Jedem eine Hook-Formel aus `daten/hooks.json` zuordnen, und abwechseln: Fünf
Beiträge aus einer Quelle mit derselben Hook-Form wirken wie eine
Content-Fabrik.

Reihenfolge: die stärkste Behauptung zuerst, die Geschichte in der Wochenmitte,
der Mechanismus zuletzt, wenn die, denen die ersten gefallen haben, darauf
warten.

## Ausgabe

```
QUELLE: «Warum Ihre Praxis auf Google Maps nicht auftaucht» (Blogartikel, 1'400 Wörter)

GEFUNDEN  3 Behauptungen, 4 Zahlen, 1 Geschichte, 3 Mechanismen, 0 Fehler, 2 zitierbare Sätze

WOCHE
DI  #11 Mythos-Bruch   Nicht der Algorithmus ist schuld, wenn die Praxis fehlt
MI  #9  Szene          "Wir stehen doch auf Google."
DO  #5  Liste          3 Einstellungen, die Praxen im Google-Profil übersehen

Sag «schreib Dienstag», dann entwerfe ich ihn.
```

Dann auf Wunsch entwerfen, einen nach dem anderen, jeweils über /li-post und
/li-human. Nicht vier fertige Beiträge auf einmal abladen, sie klingen dann alle
gleich und keiner wird bearbeitet. (Ausnahme: der Autopilot /li-woche, der
bewusst alle Beiträge einer Woche liefert.)
